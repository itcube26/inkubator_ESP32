# Инкубатор на ESP32 — Версия 2.0 (Руководство по прошивке)

## Что изменено в версии 2.0:
- **Обесточивание обмоток ULN2003**: функция `releaseStepperOutputs()` отключает подачу напряжения на мотор 28BYJ-48 после завершения шагов. Мотор и драйвер остаются холодными.
- **Маятниковый наклон**: лоток наклоняется на угол 45° влево, выдерживает интервал (по умолчанию 2 часа), затем наклоняется на 45° вправо. Провода не перекручиваются.
- **Сохранение настроек (NVS Flash)**: уставка температуры, день инкубации, гистерезис и пресеты птицы сохраняются во Flash микроконтроллера через библиотеку `Preferences.h`.
- **Защита от перегрева**: аппаратное аварийное отключение реле при температуре выше 39.5 °C.
- **Пин реле**: переведен на безопасный GPIO 4 для исключения ложного включения при старте платы.

## Сборка:
- **Arduino IDE**: Откройте `incubator_web.ino`, выберите плату `ESP32 Dev Module`, скорость 115200 бод.
- **PlatformIO**: `pio run -t upload`

# Инкубатор на ESP32 — управление через Wi-Fi (точка доступа + сайт)

Один скетч объединяет все рабочие примеры репозитория:
**DHT11** (температура/влажность), **реле** (нагреватель), **шаговый двигатель**
(переворот лотка) и **OLED** (экран). ESP32 поднимает собственную точку
доступа и веб-страницу для управления инкубатором с телефона или ПК.

## Как пользоваться

1. Откройте Arduino IDE, установите поддержку **ESP32** ( Boards Manager → `esp32 by Espressif`).
2. Установите библиотеки (Sketch → Include Library → Manage Libraries):
   - `DHT sensor library` (Adafruit) + `Adafruit Unified Sensor`
   - `Adafruit SSD1306` и `Adafruit GFX Library`
   - `AccelStepper` (waspinator)
3. Откройте `incubator_web/incubator_web.ino`, выберите плату **ESP32 Dev Module** и загрузите скетч.
4. На телефоне/ПК найдите Wi-Fi сеть **«Inkubator»** (пароль `12345678`), подключитесь к ней.
5. Откройте в браузере: **http://192.168.4.1**

## Возможности сайта

| Блок | Что делает |
|---|---|
| Температура / Влажность | живые данные с DHT11, обновление каждые 2 с |
| Обогрев | статус нагрева, кнопка «Включить вручную» / «Выключить», режим авто/ручной |
| Задать температуру | ползунок уставки 30–42 °C (по умолчанию 37.5 °C) |
| Поворот лотка | кнопка ручного переворота + тумблер авто-переворота (раз в 10 часов) |
| Система | аптайм и кнопка перезагрузки ESP32 |

## Схема подключения (пины из примеров репозитория)

| Компонент | Пин ESP32 | Пример-источник |
|---|---|---|
| DHT11 (data) | GPIO 13 | `DHT11/DHT11.ino` |
| Реле (IN) | GPIO 16, **активный LOW** | `relay/relay.ino` |
| OLED SDA / SCL | GPIO 21 / 22 (адрес 0x3C) | `oled/oled.ino` |
| ULN2003 IN1..IN4 | GPIO 19, 18, 5, 17 | `stepper_motor/stepper_motor.ino` |

## Логика работы

- **Терморегулятор**: гистерезис ±0.3 °C вокруг уставки. Нет данных с датчика —
  нагрев запрещён (защита от перегрева).
- **Ручной режим**: включается кнопкой на сайте, реле держится включённым,
  пока не выключить; повторное нажатие возвращает в авто.
- **Переворот лотка**: на 2048 полушагов (пол-оборота 28BYJ-48), выполняется
  фоново через AccelStepper — сайт и датчики при этом не «зависают».
- **Авто-переворот**: раз в `AUTO_TURN_INTERVAL` часов (по умолчанию 10),
  отключается кнопкой «Авто» на сайте.

## Настройки (в начале скетча)

```cpp
const char* AP_SSID     = "Inkubator";   // имя точки доступа
const char* AP_PASSWORD = "12345678";    // пароль Wi-Fi
#define DEFAULT_SET_TEMP   37.5f         // уставка температуры
#define HYSTERESIS         0.3f          // гистерезис нагрева
#define AUTO_TURN_INTERVAL 10            // авто-переворот, часов
```

## Сборка без Arduino IDE (PlatformIO)

```bash
cd incubator_web
pio run          # проверка сборки
pio run -t upload --upload-port /dev/ttyUSB0   # прошивка
```

## Частые проблемы

- **Страница не открывается** — убедитесь, что подключены именно к сети
  `Inkubator` (а не к домашнему Wi-Fi), и вводите `http://192.168.4.1`
  (именно `http://`, иначе браузер может искать в поиске).
- **OLED не показывает** — проверьте адрес 0x3C и питание; без дисплея всё
  остальное работает (скетч это переживает).
- **Реле ведёт себя «наоборот»** — в этом модуле активный уровень LOW,
  в скетче это учтено.

### Реле: лампочка включается при старте ESP32, но не реагирует на кнопку сайта

Две разные причины — лечатся по отдельности.

**1) Включение при подаче питания / перезагрузке.**
GPIO16 (D2) на большинстве модулей ESP32 имеет внутренний подтягивающий
резистор к земле, а до выполнения `setup()` пин вообще не настроен. Модуль
реле с активным LOW в этот момент «видит» ноль и замыкает контакты — лампочка
горит ~1–3 секунды, пока загрузится скетч. Программно это полностью не
лечится, поэтому:
   - **надёжнее всего** — переставить провод IN реле на **GPIO4** (или GPIO25):
     в скетче достаточно поменять `#define RELAY_PIN 16` → `4`. Эти пины не
     имеют подтяжки вниз и не дёргаются при старте;
   - либо подтянуть D0/GPIO16 к 3V3 резистором 10 кОм;
   - либо питать реле от отдельного 5 В, а не от вывода 5V платы ESP32 через USB.

Для проверки в `setup()` добавлен тест: при старте реле делает два коротких
щелчка (120 мс). Если щёлкнуло — пин и прошивка живы, проблема в уровне на
линии при загрузке. Если нет — проверьте питание модуля реле (VCC/GND) и
переходник/провода.

**2) Кнопка «Включить вручную» не включает реле во время работы.**
Причина была в двух местах:
   - страница хранила состояние кнопки локально (`manualHeat`) и после каждого
     опроса `/status` перезаписывала его, из-за чего нажатие могло отправить
     `/heat?on=0` вместо `on=1`; теперь кнопка шлёт команду, отталкиваясь от
     состояния, которое вернуло **устройство**, и блокируется на время запроса;
   - обработчик `/heat` менял флаги, а `loop()` мог их перезаписать своим
     терморегулятором. Теперь запись идёт под `noInterrupts()/interrupts()`,
     `heating`/`manualHeat` объявлены `volatile`, и реле дёргается сразу в
     обработчике, не дожидаясь следующего прохода `loop()`.

Диагностика: откройте монитор порта (115200) — каждое нажатие печатает строку
вида `/heat?on=1 -> реле ВКЛ (LOW)`. Если строки нет — запрос до ESP32 не
доходит (обрыв связи, страница открыта в демо-режиме/из файла, а не с
192.168.4.1). Если строка есть, а лампочка не горит — проблема аппаратная
(пункт 1 или питание реле).

Проверить сайт без железа можно, открыв `web_preview.html` — там работает
демо-режим с имитацией нагрева.
